## Technical Notes

### Signing Key Location
- Private: `~/.tauri/mosaic-drive.key` (KEEP SECRET)
- Public: `~/.tauri/mosaic-drive.key.pub`

### Auto-Updater
- Endpoint: GitHub Releases (`latest.json` auto-generated by CI)
- Config: `src-tauri/tauri.conf.json` → `plugins.updater`

### Build Commands
```bash
# Development
npm run tauri dev

# Production build (Apple Silicon)
npm run tauri build

# Universal build (Intel + Apple Silicon)
rustup target add x86_64-apple-darwin
npm run tauri build -- --target universal-apple-darwin
```

### Server
- SSH: `ssh -p2250 jody@mosaic.site`
- S3 Endpoint: `https://s3.mosaic.site`
- DMG Upload Path: `/tmp/` (for manual releases)
