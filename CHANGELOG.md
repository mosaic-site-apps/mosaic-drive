# Changelog

All notable changes to Mosaic Drive will be documented in this file.

## [0.2.0] - 2025-01-11

### Added
- Multi-select files with Shift+Click (range) and Cmd+Click (toggle)
- Bulk delete for selected files
- Bulk download for selected files with folder picker
- Search/filter functionality to find files quickly
- Auto-updater via GitHub Releases

## [0.1.0] - 2025-01-10

### Added
- Initial release
- Persistent login (stays logged in between sessions)
- List view and Column view toggle
- Drag & drop uploads with visual feedback
- Concurrent uploads (up to 3 simultaneous)
- Upload queue with pause/resume/skip controls
- Auto-increment duplicate filenames
- Trash system (move to trash, empty trash)
- Hidden .keep files for empty folders
- Custom Mosaic icon
- Apple Silicon (aarch64) build
- Single file download with save dialog
- Folder download as ZIP
- Right-click context menu (Download, Trash, New Folder)
